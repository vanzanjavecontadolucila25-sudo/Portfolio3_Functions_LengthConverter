Submitted in fulfillment of the subject BES 10a, this Python project is a length conversion tool that translates measurements between metric and standard systems. The program relies primarily on user-defined functions (def) to split the code into organized, reusable blocks for managing each menu and calculation. Inside these functions, if-elif-else conditional statements direct the user through the different conversion choices, while try-except blocks provide basic error handling by catching non-numeric inputs before they can cause a system crash. Finally, print statements are used throughout the script to display the final conversion results and format the console interface for a cleaner layout.
